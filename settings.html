Deep Context
Let the agent read what's under your cursor and in the focused window for better answers. Stays on your Mac — sent only to OpenAI for the reply, never stored by us.
🪟
Full window text
Read the whole window you're in, not just under the cursor — more context for "what am I looking at". Text only, via Accessibility; fast.
📸
Window screenshot (vision)
Send a small screenshot of your focused window each turn so the agent can actually see the UI — images, layout, buttons. Needs Screen Recording permission; adds a little latency.
⚡
Agentic shell
Let the agent run commands, read files, and drive apps on your Mac. Powerful — leave off unless you want it acting, not just answering.
🤝
Delegate tasks to
Which background agent runs the work she hands off. pi is fast (deepseek); Claude is more capable but slower. "Don't delegate" makes her do everything inline instead.
🖥️
Show background task terminals
When the agent hands a slow job to a background agent, open a Terminal window tailing its live output so you can follow along.
🖥
Activity window
Open a window that shows what the agent hears, says, and runs during a live conversation.
